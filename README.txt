# Adventure Based Training Center - Naula Puzzle Game

A browser-based 30-piece picture puzzle for school prefect students.

## How to run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Firefox, Edge, or another modern browser.
3. Enter the player's name, school, and team number.
4. Press **Start Puzzle**. The timer starts immediately.
5. Select one tile, then another tile to swap their positions until the picture is complete.
6. When finished, take a screenshot of the completed screen and send it to **0717043887** on WhatsApp. The **Open WhatsApp** button opens the chat and prepares a result message; attach the screenshot manually.

## Files
- `index.html` — page layout and player form
- `style.css` — responsive visual design
- `script.js` — puzzle logic, tile swapping, timer, and WhatsApp link
- `assets/adventure-puzzle.jpg` — picture supplied for the puzzle

## Notes
- The puzzle contains 30 square tiles arranged in a 6-column × 5-row grid.
- No server or installation is required; the game runs locally in a browser.
- Google Fonts are optional and require an internet connection. The page uses fallback fonts if offline.
- The website does not automatically capture or send screenshots. Players must take and attach their screenshot themselves.
